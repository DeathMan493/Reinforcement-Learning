# Reinforcement Learning

This repository contains lab programs for Reinforcement Learning coursework.

## Lab 1

The `Lab 1` folder contains:

- `cartpole_lab1.py`: Gymnasium CartPole-v1 environment setup, space exploration, and one complete random-agent episode.
- `tic_tac_toe_rl.py`: Tic-Tac-Toe Q-learning example showing RL states, actions, rewards, terminal states, policy, and value function.

## Run

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the lab files:

```bash
python "Lab 1/cartpole_lab1.py"
python "Lab 1/tic_tac_toe_rl.py"
```
